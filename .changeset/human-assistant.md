A calmer, more human assistant. The generated chat box has a new black-and-white design (light and dark, smooth CSS-only motion, typing indicator, icon buttons, greeting by time of day) and sends the current page path and title as context. The system prompt now asks for a warm, natural spoken tone (and natural Telugu and Hindi instead of word-for-word translation), and the page list is shorter. Opening a page now takes one model call instead of two when the model says its line in the same reply.
