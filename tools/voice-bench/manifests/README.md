# Audio manifests

Keep recordings and generated manifests outside the repository. Run the CLI's `manifest` command on a WAV directory and an ID/reference TSV. Set a language and the actual corpus licence. Attach tags such as `code-mixed`, `quiet`, `phone` or `numbers` to each manifest item. The `stt --tag-filter code-mixed` option evaluates only matching items. Use consistent tags and the same utterances when comparing systems.
